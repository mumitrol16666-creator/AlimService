# Alim Service — копия для показа

Демонстрационная копия сайта и демо-системы. Закрыта от поисковиков (`noindex`, `robots.txt: Disallow`).
Данные в демо-системе примерные. Не является официальным сайтом Alim Service.

- `site/` — сайт (собирается `python3 build/build_site.py` из `build/content.py`)
- `demo/` — демо системы приёмки, работает в браузере без сервера
- `index.html` — стартовая страница показа, кнопка «Скачать для показа без интернета»
